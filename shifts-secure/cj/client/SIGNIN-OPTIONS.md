# Ways a client could sign in

This note is for the client portal only. It does not change sign-in. Nothing here is turned on.

The portal should open for one client and that client’s sites. A sign-in that can be shared, guessed, or left open on a shared computer is a poor fit.

## 1. Emailed magic link

The client enters the email address the office already has. The portal emails a link. Opening the link signs them in for a short time. The link stops working after that, and after it has been used.

**Pros.** No password to remember or reset. The office already writes to clients by email. A link that dies quickly is hard to reuse later.

**Cons.** Whoever can open that inbox can open the portal. Some phones make the link awkward. If the email is slow, the person waits.

## 2. One-time code by email or text

The client enters an email address or a mobile number. They receive a short code and type it in. The code works once, for a few minutes.

**Pros.** Nothing is stored as a password. A code in a text is easy on a phone. An old code cannot be used next month.

**Cons.** Text messages cost money and need a correct mobile number. Email codes have the same inbox problem as a magic link. A person can be talked into reading a code to someone else.

## 3. Invite link, then a password

The office sends a one-time invite. The client sets a password and uses it after that. Forgotten passwords go through a reset email.

**Pros.** Familiar. After the first visit they do not need to wait for an email. It can match the way the main app already signs people in.

**Cons.** Passwords are forgotten, reused, and written down. A shared office password would let more people in than the client intended. Reset emails are another thing to build and watch.

## Recommendation

Use an emailed magic link.

Clients open this portal now and then, not every day. A link from the same address that already sends their invoices is enough, if the link expires, works once, and is tied to that one client. Offer a one-time email code as a backup when the link is hard to tap. Leave passwords until clients ask for them.
